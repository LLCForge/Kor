# kor-proxy

**What it does.** A local OpenAI-, Anthropic- and Gemini-compatible gateway, the Rust port of CLIProxyAPI (MIT, see LICENSE-CLIProxyAPI), started by `kor proxy`.

**What it does not do.** Not used unless the user starts it; subscription OAuth flows are the user's own choice and risk.

**Called by:** `kor-cli`, `kor-desktop`.

Module map: the `//!` comment at the top of `src/lib.rs`. Where it sits in the whole: [ARCHITECTURE.md](../../../ARCHITECTURE.md).
